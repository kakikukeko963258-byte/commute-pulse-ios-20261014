## 位置情報とシミュレーション

- 実際の位置情報を使う場合、実機上で取得・処理されること、拒否・制限時の挙動を確認する。
- デバッグ用シミュレーションは、実測の位置・運行情報と見分けられる表示にする。シミュレーション結果を実際の通勤状況として誤認させない。
- OS の位置情報権限を「許可しない」「使用中のみ」「正確な位置情報オフ」などに切り替え、各状態の説明が適切であることを確認する。

## Widget と Live Activity

- Widget の表示内容、更新タイミング、古いデータの表示状態を確認する。Widget の再読み込みは OS のスケジュールや予算に制約されるため、更新要求を出した直後に画面が必ず更新される前提にしない。
- Live Activity では、Activity.request が受理されたことと、ロック画面や Dynamic Island に実際に表示されることを別々に記録する。OS 設定、端末状態、許可状態などにより表示されない場合も確認する。
- Live Activity の時間経過表示は、毎秒タイマーが動くことを前提にしない。開始・終了時刻などの Date を基準に、アプリが前面にいない間も経過時間が正しく再計算されることを確認する。
- 端末の Live Activities 設定や通知設定を変えたときの挙動を確認する。
